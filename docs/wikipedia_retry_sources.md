# Fontes da Wikipedia para retry

Este arquivo contém itens que falharam no primeiro download e alternativas aproximadas para tentar baixar novamente.

Fonte dos erros: log local do comando `python -m scripts.ingest_wikipedia_raws --start 11 --sleep 5 --retries 5 --retry-sleep 15`.

## Itens que falharam no log

- Agrupamento de dados
- Gradiente descendente
- Função de ativação
- Extração de informação
- Lematização
- Semântica vetorial
- Saco de palavras
- Memória de longo curto-prazo
- Autoencoder
- Codificador-decodificador
- Aprendizagem auto-supervisionada
- Modelo génerativo
- Notação Big O
- Otimização matemática
- Qualidade de dados
- Cluster de computadores
- Viés algorítmico
- Proteção de dados pessoais
- Solução de problemas

Alguns itens acima podem continuar falhando se a Wikipedia em português não tiver artigo com esse título exato. Quando isso acontecer, use um artigo mais geral já baixado ou remova o item da lista.
